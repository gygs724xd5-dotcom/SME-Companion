# SME Companion Roadmap

## V5

V5 establishes the AI-native Business Operating System architecture.

Focus:

- Define 20 business domains.
- Standardize Business Skill schema.
- Establish Business Reasoning Engine design.
- Define memory ownership.
- Define workflow lifecycle.
- Define response envelope and response intelligence.
- Document developer extension rules.
- Preserve V4 behavior while creating the target architecture.

Outcome:

SME Companion has a clear architecture foundation for becoming a business companion rather than a chatbot.

## V5.1

V5.1 should begin structured migration toward the architecture.

Focus:

- Create skill registry structure.
- Normalize existing skills into the canonical schema.
- Add domain metadata.
- Introduce response envelope concept behind existing behavior.
- Improve diagnostics for routing, reasoning, workflow, and response selection.
- Map existing workflows to lifecycle states.

Outcome:

The V4 foundation gains V5 structure without changing user-facing behavior unnecessarily.

## V5.2

V5.2 should expand business capability and continuity.

Focus:

- Grow toward 100+ Business Skills.
- Add durable workflow memory patterns.
- Strengthen memory conflict rules.
- Add transformation memory for generated business assets.
- Improve workflow chaining.
- Add domain-level dashboards and business intelligence summaries.
- Introduce stronger LLM context contracts.

Outcome:

SME Companion becomes capable of managing multi-step business work across domains with reliable continuity.

## V6

V6 should make SME Companion a full Business Operating System.

Focus:

- Multi-store and multi-user state ownership.
- Role-aware permissions.
- Tool and integration marketplace.
- Financial, inventory, CRM, document, and supplier integrations.
- Proactive business alerts.
- Executive planning and governance.
- Auditable business memory and decision history.
- Advanced analytics and simulation.

Outcome:

SME Companion becomes the primary AI operating layer for SME decision-making, workflows, records, and growth.

## Long-Term Direction

The long-term product direction is:

```text
Helpful assistant
  -> Business companion
  -> AI-native operating system
  -> Intelligent business execution layer
```

Each release should preserve architectural clarity:

- Business knowledge remains structured.
- Reasoning remains explainable.
- Workflow state has one owner.
- Memory has purpose and provenance.
- Responses are composed through a single envelope.
- LLMs support the system instead of replacing it.
